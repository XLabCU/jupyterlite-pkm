# Glossary

A collection of key terms and definitions used throughout this course.

## Key Terms

### Algorithm
A step-by-step procedure for solving a problem or accomplishing a task. ^algorithm

### Data Frame
A two-dimensional data structure with rows and columns, similar to a spreadsheet or SQL table. ^dataframe

### Function
A reusable block of code that performs a specific task. Functions can accept inputs (parameters) and return outputs. ^function

### Variable
A named container that stores a value in memory. Variables can hold different types of data like numbers, text, or more complex structures. ^variable

### Loop
A control structure that repeats a block of code multiple times. Common types include `for` loops and `while` loops. ^loop

### Conditional
A control structure that executes different code based on whether a condition is true or false. Implemented using `if`, `elif`, and `else` statements. ^conditional

## Data Types

### Integer
A whole number without decimal points (e.g., 1, 42, -7). ^integer

### Float
A number with decimal points (e.g., 3.14, -0.5). ^float

### String
A sequence of characters, typically enclosed in quotes (e.g., "Hello, World!"). ^string

### Boolean
A value that can only be `True` or `False`. ^boolean

### List
An ordered collection of items that can be modified (mutable). ^list

### Dictionary
A collection of key-value pairs for storing related data. ^dictionary
