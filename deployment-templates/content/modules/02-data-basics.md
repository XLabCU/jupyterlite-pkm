### Loading Data

Data can be loaded from various sources:

- CSV files
- JSON files
- Databases
- APIs

### Data Inspection

Always start by understanding your data:

```python
df.head()      # First 5 rows
df.info()      # Data types and memory
df.describe()  # Statistical summary
```
